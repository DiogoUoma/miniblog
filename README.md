# 📝 MiniBlog - Blog com React e Firebase

Projeto de blog simples e funcional desenvolvido com React, Vite e integração com Firebase. Permite que usuários criem, visualizem e interajam com postagens, com autenticação segura e persistência em nuvem.

## 🎯 Objetivo

Treinar o desenvolvimento de uma aplicação fullstack utilizando Firebase como backend (autenticação + banco) e React como frontend SPA.

## 🛠 Tecnologias utilizadas

- React 18
- Vite
- Firebase (Authentication + Firestore)
- React Router DOM
- JavaScript (ES6+)
- HTML/CSS

## ✨ Funcionalidades

- 🧑 Cadastro e login de usuários
- ✍️ Criação de postagens
- 📃 Listagem de todos os posts
- 🔍 Detalhes de cada post
- 🧼 Layout limpo e responsivo
